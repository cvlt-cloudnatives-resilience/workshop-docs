### [DevOps Meets ResOps](https://cvlt-cloudnatives-resilience.github.io/workshop-docs/resops-commvault-docs/)

Two hours, seven chapters, one Azure VM. Stand up a real workload, protect
it with Commvault Cloud, compromise it on purpose, choose a recovery point,
prove recovery with a restore drill, and gate a pipeline on the result.
Every verdict is read from evidence the run wrote.

Each guide is one self-contained page. It opens offline, it prints, and it
follows your light or dark preference.
